# Presentation slides

- `split_computing_talk.pptx`: draft deck for the EE289 final presentation (12 slides, ~10 minute talk, speaker notes on every slide). Numbers come from `results/summary.csv` (two-laptop run, 2026-11-21).
- `build.js`: pptxgenjs script that generates the deck. Run with `REPO=<repo root> SKILL=<pptx skill dir> node build.js out.pptx` after `npm install pptxgenjs react-icons react react-dom sharp`. Editing the .pptx directly in PowerPoint is fine too.

Update slides 6–10 after the GPU-verified re-run.
